# Assessing AI-assisted work

## Rubric for AI-assisted work, 20 points (Appendix A, Table A.7)
| Criterion | Excellent (4) | Adequate (2 to 3) | Weak (0 to 1) |
|---|---|---|---|
| Safe use | Data class checked; only allowed data and tools used; no personal data | Rules followed, but the check is not recorded | Personal or confidential data entered, or an unapproved tool used |
| Prompt design | Pattern suited to the task; constraints and verification built in | Reasonable prompt with gaps, such as no source requirement | Vague prompt; pattern unsuited to the task |
| Verification | Every number recomputed; claims traced; known-answer or broken-version test where relevant | Main figures checked; some claims untraced | Output used as given |
| Critique and judgement | Failures identified and explained; author's own additions and rejections clear | Some failures noted; little on what the author added | No critique, or praise only |
| Transparency | Complete prompt log; accurate, specific disclosure | Log incomplete; generic disclosure | No log or disclosure |

A score of zero on safe use caps the AI component at zero, whatever the other scores. The rubric sits alongside the subject rubric for the deliverable; it does not replace it.

## Which data may go into which tool (Appendix A, Table A.1)
| Data class | Public AI tool, personal account | Enterprise AI tool, no training on inputs | AI feature in an approved system | Approved service hosted in-country |
|---|---|---|---|---|
| Public | Yes | Yes | Yes | Yes |
| Internal | No | Yes | Yes | Yes |
| Confidential business | No | With conditions | With conditions | Yes |
| Personal | No | No | With conditions | With conditions |
| Health | No | No | No | With conditions |
