# Appendix A: generative AI and prompt engineering

Companion files for Appendix A of *Information Technology Project Management: Traditional Foundations, Agile Delivery and AI-Enhanced Practice*.

| File | What it is |
|---|---|
| `prompt_library.md` | The fourteen prompt patterns, with templates and checks |
| `prompt_log_template.csv` | Prompt log template (Table A.6); the first row is the book's example. Keep one log per deliverable |
| `ai_rubric.md` | Rubric for AI-assisted work (Table A.7) and the data rules (Table A.1) |

The practical rule for students: never enter personal data, health data, credentials, security findings or confidential information from a real organisation into an AI tool, unless your institution has approved that use in writing. The HealthSync case is fictional and safe to use.
