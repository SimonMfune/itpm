# AI-enhanced labs

**Chapters:** Chapter 13 and Appendix A of *Information Technology Project Management: Traditional Foundations, Agile Delivery and AI-Enhanced Practice*
**Files:** `appendixA/`, `data/healthsync_tickets_test.csv`, `test_set_template.csv`, `ai_usage_policy_template.md`

## Purpose

Practise the prompt patterns of Chapters 1 to 12 and the governance practices of Chapter 13.

## You will produce

1. A personal prompt library with one tested prompt for each of five chapters of your choice.
2. A test set and acceptance rule for one reusable prompt.
3. A prompt log covering your capstone work.
4. A one-page AI usage policy for your capstone team.

## Steps

1. Choose five patterns from `appendixA/prompt_library.md`. Adapt each to a real task from your labs or capstone, run it and record what you checked in the prompt log.
2. Reproduce Worked Example 13.1 with `data/healthsync_tickets_test.csv`: 40 hypercare tickets (3 priority 1, 10 priority 2, 27 priority 3) with agreed priorities. Write the acceptance rule **before** you run anything. Test two versions of a ticket-priority prompt and decide whether either can be used.
3. Build a test set of your own for one reusable prompt, using `test_set_template.csv`.
4. Keep one prompt log for your capstone (`appendixA/prompt_log_template.csv`).
5. Write your team's AI usage policy from `ai_usage_policy_template.md`, applying CareGrid's policy (Chapter 13) to your project.

## Rules

- Use only tools your institution allows. Never enter personal data, credentials or confidential data from a real organisation.
- Check every number, citation and claim. Recompute calculations yourself.
- Disclose AI use in each deliverable in one or two sentences.

## Before you submit

- Check every figure you report. Recompute anything a tool or an AI assistant produced.
- If you used AI, keep a prompt log (`appendixA/prompt_log_template.csv`) and add a one- or two-sentence disclosure to your deliverable.
- Name each file with your team or student ID and the lab number.
