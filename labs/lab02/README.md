# Lab 2: Initiating the project and stakeholder mapping

**Chapters:** Chapter 3 of *Information Technology Project Management: Traditional Foundations, Agile Delivery and AI-Enhanced Practice*  

## Purpose
Turn the HealthSync case into the core initiation documents.

## You will produce

1. A spreadsheet that reproduces Worked Example 3.1 (the HealthSync business case) and the sensitivity tests in Table 3.2, using formulas, not typed results.
2. A project charter for HealthSync that reconciles clinicians' usability needs with the Data Protection Officer's security demands (**Assignment 1**).
3. A stakeholder register with a power/interest grid.

## Steps

1. Read the case briefing in `case/`, especially the objectives, budget, benefits and cast of characters.
2. Build the business case spreadsheet: cash flows by year, the 18% discount rate, NPV and payback. Then change one assumption at a time to reproduce Table 3.2.
3. Draft the charter using the template in `templates/` (Appendix C, Section C.2). Show how you resolved the tension between fast, simple screens for doctors (Dr Mwila Sakala) and lawful, secure processing (Grace Tembo). State the decision rights.
4. List the stakeholders in the register with their interest, influence and engagement actions, and place them on a power/interest grid.

## Tips

- An objective without a measure, a baseline and a date is a wish. Check each against the SMART test.
- Name a benefit owner in the business, not in IT.
