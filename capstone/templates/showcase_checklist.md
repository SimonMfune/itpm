# Showcase checklist

- [ ] One user journey shown from start to finish
- [ ] Each story shown is tied to the backlog, with its status against the Definition of Done
- [ ] Stories not done are named, with what we would do next
- [ ] Ready for questions on quality, security and data
- [ ] Anything that does not work is said plainly, not hidden
- [ ] Forecast against actual, with the burn-up
- [ ] Timed rehearsal done; every member has a part
