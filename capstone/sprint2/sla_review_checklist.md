# SLA review checklist

Service reviewed: ______  Plan or tier: ______  Date of the SLA version: ______

| Area | Question | What the SLA says | Gap or risk for your project |
|---|---|---|---|
| Availability | What availability is promised, and how is it measured (per month, per region, per service)? | | |
| Credits | What credit is paid when the target is missed? Is it automatic or must you claim it? Is there a cap? | | |
| Exclusions | What does not count as downtime (maintenance, your own configuration, force majeure, free tiers)? | | |
| Support | Response times by priority; hours; channels | | |
| Data location | Where is data stored and processed? Can you choose the region? | | |
| Security | Certifications or reports offered (for example SOC 2, ISO/IEC 27001); breach notification time | | |
| Exit | How do you get your data back, in what format, and how long is it kept after you leave? | | |
| Changes | Can the supplier change the terms, and with how much notice? | | |

**Conclusion:** does the SLA support your project's own service targets? What will you do about the gaps?
