# Information Technology Project Management: companion repository

Companion files for *Information Technology Project Management: Traditional Foundations, Agile Delivery and AI-Enhanced Practice* by Simon Mfune (DevDash Professional, an imprint of DevDash Innovations).

## Contents

| Folder | What it holds | Book reference |
|---|---|---|
| `case-bible/` | The HealthSync Case Bible, the full record of the main case | Used throughout |
| `labs/` | Data and starter files for Labs 1 to 12 | Lab link boxes in each chapter |
| `templates/` | Editable templates: one Word document and one Excel workbook | Appendix C |
| `appendixD/` | Python script, data and CI workflow | Appendix D |

## For instructors

The Instructor's Manual is available to verified instructors on request. Write to the contact address on the repository owner's profile page from your institutional email, giving your name, institution and course. Please do not request the manual, or post answers to the odd-numbered questions, in issues or pull requests, because they are public.
