# Information Technology Project Management: companion repository

Companion files for *Information Technology Project Management: Traditional Foundations, Agile Delivery and AI-Enhanced Practice* by Simon Mfune (DevDash Professional, an imprint of DevDash Innovations).

Repository: https://github.com/SimonMfune/itpm

## What is here

| Folder | Contents | Used in |
|---|---|---|
| [`case/`](case/) | HealthSync Case Bible, student edition: the fixed facts of the running case | Every chapter |
| [`data/`](data/) | HealthSync data sets for the labs | Labs 3 to 12 |
| [`docs/`](docs/) | Change request CR-014 | Lab 10, Assignment 4 |
| [`labs/`](labs/) | Instructions and starter files for Labs 1 to 12 and the AI-enhanced labs | Lab link boxes in Chapters 1 to 13 |
| [`capstone/`](capstone/) | Capstone brief, rubric, case briefs, sprint packs and templates | Chapters 9, 10 and 14 |
| [`templates/`](templates/) | Editable project document templates in Word and Excel | Appendix C |
| [`appendixA/`](appendixA/) | Prompt library, prompt log template and AI rubric | Chapter 13 and Appendix A |
| [`appendixD/`](appendixD/) | Python script, data and CI workflow | Appendix D |

All figures match the book. Where the book gives a result, such as a cost, a percentile or a control limit, the data reproduces it.

## How to use it

Download everything with **Code**, then **Download ZIP**, or clone the repository. CSV files open in any spreadsheet. The Python files need Python 3.11 or later; see `appendixD/README.md`.

## For instructors

The Instructor's Manual is available to verified instructors on request. Write to the contact address on the repository owner's GitHub profile from your institutional email, giving your name, institution and course. Please do not request the manual, or post answers to the odd-numbered questions, in issues or pull requests, because they are public.

The complication cards (Case Bible, Section 11) are in the Instructor's Manual, not here, so that students do not see a card before its week.
